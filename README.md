# TFG: Implementación de modelos de lenguaje en un robot para permitir la comunicación oral

El Trabajo Fin de Grado tiene como objetivo dotar a un robot de la capacidad de mantener una interacción oral con los usuarios mediante el uso de modelos de lenguaje. Para ello, se desarrollará una arquitectura que integre tres componentes fundamentales:

1) Reconocimiento automático del habla (ASR, Automatic Speech Recognition), encargado de convertir la voz del usuario en texto.
2) Procesamiento del lenguaje natural (NLP), mediante modelos de lenguaje que permitan interpretar las preguntas o comandos recibidos y generar respuestas adecuadas.
3) Síntesis de voz (TTS, Text-to-Speech), para transformar el texto de la respuesta en audio inteligible que el robot pueda reproducir.

El proyecto explorará tanto la implementación local en el propio robot como la ejecución en un servidor externo, al que el robot se conectará a través de internet en caso de que los requisitos computacionales de alguno de los módulos no puedan satisfacerse con el hardware embarcado.

De este modo, el trabajo combina técnicas de inteligencia artificial, robótica y computación distribuida, con el fin de habilitar un sistema de comunicación oral fluido que mejore la interacción entre humanos y robots en escenarios de servicio o  emergencia.
